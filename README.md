# Sub — مترجم الروايات والملفات

ترجمة PDF / EPUB / TXT بين الإنجليزية والعربية واليابانية عبر APIs مجانية (Gemini, Groq, Cerebras, OpenRouter, Mistral)،
مع مسرد موحد، ترجمة متوازية، ومدقق جراحي يعدل الفقرات الضعيفة فقط بالـ ID.

## التشغيل
```bash
pip install -r requirements.txt
python app.py          # ثم افتح http://127.0.0.1:7860
```
- الدخول: أي اسم مستخدم + كلمة السر الأولية `2222`، وبعدها يجبرك الموقع على تغييرها من تبويب الإعدادات.
- أضف مفاتيحك من تبويب **API** (تُحفظ في مجلد `data/` على جهازك ولا تُرفع لـ GitHub).
- لو شغّلته على سيرفر: `HOST=0.0.0.0 PORT=7860 python app.py`. المجلد `data/` لازم يكون على قرص دائم.
  وبعض الاستضافات المجانية تمسح القرص عند إعادة التشغيل فتضيع المفاتيح.

## خط العمل
1. قراءة الملف وتقسيمه لفقرات بمعرفات `P_1, P_2, ...` مع إحداثياتها
2. بطاقة سياق (شخصيات وجنسها، مصطلحات، نبرة) تُرفق مع كل طلب، وتقدر تعدلها
3. ترجمة متوازية على كل المفاتيح المفعّلة مع احترام حد الطلبات لكل مفتاح وتأخير بسيط بين الإطلاقات
4. تدقيق جراحي: يقرأ الأصل والترجمة ويرجع تصحيحات للفقرات الضعيفة فقط (صارم/متوسط/دقيق)
5. معاينة وتعديل يدوي وأوامر بالذكاء الاصطناعي، ثم توليد PDF/EPUB/TXT

## حدود صريحة
- لم تُختبر الاتصالات مع المزودين الحقيقيين من بيئة التطوير، جرّب زر **اختبار** لكل مفتاح، وأسماء النماذج قابلة للتعديل.
- الصفحات الممسوحة ضوئياً (صور بدون نص) والنص المكتوب داخل الصور غير مدعومة بعد (يحتاج OCR).
- PDF المخرج يحتفظ بالصور والرسومات ويستبدل النص في أماكنه (معكوساً لليمين عند العربية). النص العربي الأطول يُصغَّر خطه عند الحاجة.
- مخرج PDF الياباني يحتاج خطاً: ضع `NotoSansJP-Regular.ttf` في مجلد `fonts/`.
- حدود الطبقات المجانية تتغير، والترجمة تتوقف مؤقتاً عند الوصول لها وتُستكمل بزر **استكمال**.
- عداد الصرف يحسب المفاتيح المدفوعة فقط ويوقفها عند السقف الذي تحدده.

## الاستضافة المجانية الثابتة (Hugging Face Spaces)
أضف في إعدادات الـ Space (Variables and secrets) هذي الأسرار:
- `SUB_PASSWORD`: كلمة السر (تبقى بعد إعادة التشغيل)
- `GEMINI_API_KEY`, `GROQ_API_KEY`, `CEREBRAS_API_KEY`, `OPENROUTER_API_KEY`, `MISTRAL_API_KEY`
  (تقدر تحط أكثر من مفتاح للمزود الواحد مفصولة بفاصلة)

قرص الـ Space مؤقت: المفاتيح وكلمة السر تبقى لأنها أسرار، لكن المهام والملفات المترجمة تضيع عند إعادة التشغيل، فنزّل ناتجك أول بأول.
